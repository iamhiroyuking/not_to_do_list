代わりの行動を用意する

「絶対にピンク色の象を想像しないでください」と言われると、どうしても頭に思い浮かべてしまいますよね。「〜しない」と念じるほど、かえってその対象を意識してしまう現象は、心理学の実験でも確かめられています。

我慢は逆効果になりうる

「お菓子を食べない」「スマホを見ない」と念じれば念じるほど、脳はかえってその対象を強く意識してしまうことがあります。

これを防ぐためには、単に禁止するのではなく「代わりに何をするか」という新しい行動で上書きするのが効果的です。この方法はさまざまな目標を対象にした実験を集めた分析でも、幅広く効果が確認されています。

「If-Then」のルール

「もし（If）スマホを触りたくなったら、その代わり（Then）本を1ページ開く」「もしイライラしたら、深呼吸を3回する」といった具合です。あらかじめ「もし〜なら、〜する」を決めておくだけで、目標を達成できる確率が上がることは、90本以上の研究を集めた分析でも支持されています。

「やらないことリスト」が辛い我慢大会にならないよう、代わりのポジティブな行動を自分の中でセットにしておきましょう。危険シグナルを事前に書いておくのは、この「If」の部分を先に言葉にしておく作業でもあります。

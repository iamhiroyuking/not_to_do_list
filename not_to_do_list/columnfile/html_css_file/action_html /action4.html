記録して可視化する

人間の記憶は驚くほど曖昧です。3日前の夜に自分が何分スマホを見ていたか、正確に答えられる人はほとんどいません。

事実はデータにしか宿らない

「最近だらけているな」というネガティブな思い込みや、「今回はうまくやれている」という楽観的な錯覚を防ぐには、毎日の行動を客観的に「記録」するしかありません。進み具合をこまめに記録すること自体が、目標の達成率を押し上げることは、多数の実験を集めた分析でも確かめられています。特に、記録が紙やアプリなど形に残る形で残されるほど、効果は大きくなる傾向があります。

1回のサボりでは、記録は途切れない

「鎖を断ち切るな（Don't break the chain）」という考え方が知られています。カレンダーにマークが埋まっていくのを見ることは、脳にとって大きな報酬になります。

ただし、このアプリでは1日休んでも記録は途切れません。連続が本当に途切れるのは、2日続けて記録できなかった時だけです。1回のサボりで積み上げがゼロになるという恐怖で自分を縛るのではなく、「1日くらいは転んでいい、ただし2日は続けない」というくらいの緩さで、記録を続けることそのものを大事にしてください。

出典

Harkin, B. et al. (2016). Does Monitoring Goal Progress Promote Goal Attainment? A Meta-Analysis of the Experimental Evidence. Psychological Bulletin, 142(2), 198–229.

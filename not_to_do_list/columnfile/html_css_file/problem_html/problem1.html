意志力は消耗する

なぜ夕方になると、つい誘惑に負けてしまうのでしょうか？「あと少しだけ勉強しようと思っていたのに、気づけば動画を1時間も見てしまった」「相場が荒れている時、冷静な判断ができずに感情的なトレードをしてしまった」。こうした挫折を経験するたびに、多くの人は「自分はなんて意志が弱いんだ」「気合が足りないからだ」と自分を責めてしまいます。

ただ、性格や根性の問題だと決めつける前に、知っておいた方がいい研究があります。

「有限のバッテリー」説は、思われているほど確立していない

意志力を「使うほど減っていくバッテリー」にたとえる説明は広く知られています。これは自我消耗（ego depletion）と呼ばれ、心理学で長く支持されてきました。ところが2016年、23の研究室が参加した大規模な事前登録追試（2,000人以上を対象）が行われた結果、効果はほとんど確認されませんでした。心理学の再現性が問い直された時期を象徴する結果のひとつです。

これは「意志力を使うと次第に効きが悪くなる」という日常の実感そのものを否定するものではありません。否定されたのは「脳内の資源が物理的に減っていく」という説明の仕方の方です。

資源が減るのではなく、気が逸れる

この結果を受けて、心理学者のインズリクトとシュマイケルは別の説明を提案しています。何かを我慢したあと意志力が発揮しにくくなるのは、燃料が切れるからではなく、「やるべきこと」から「やりたいこと」へ、注意と動機が自然に引き寄せられていくからだ、というものです。

この見方に立つと、対策は変わってきます。バッテリーを"温存"する話ではなく、注意が引き寄せられる先を先回りして塞いでおく話になります。

枯渇した時に現れるサイン

資源が減るにせよ、注意が逸れるにせよ、我慢が続いたあとに現れる兆候はよく似ています。「まあいいか」という妥協が増える。計画通りに進められなくなる。感情的になりやすく、理詰めの判断がしづらくなる。思い当たる節があるなら、それは怠惰だからではなく、判断や我慢を重ねたあとの、ごく自然な反応です。

大切な目標を守るために

だからこそ、「やらないこと」をあらかじめ決めておくことが効きます。仕組みが変わっても、この結論は変わりません。

「〇〇はしない」「作業中はスマホを別の部屋に置く」と事前にルール化しておけば、その場で気を取られる対象そのものが目の前から消えます。バッテリーを節約するというより、注意が逸れる先を先に塞いでおくと考えた方が、実際に起きていることに近いでしょう。

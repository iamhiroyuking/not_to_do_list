マルチタスクの幻想

「リスニング音声を流しながら別の作業をする」「コードを書きながらSNSの通知をチェックする」。一見、時間を有効活用しているように思えるこれらの行動こそが、あなたの脳のパフォーマンスを下げている犯人です。

脳は「並列処理」ができない

コンピュータのマルチコアプロセッサとは異なり、人間の脳（特に意識的な思考を司る前頭前野）は、複数の高度なタスクを同時に並列処理するようには設計されていません。実験心理学の研究によれば、私たちが「マルチタスク」だと思っているものの正体は、実は2つのタスク間を高速で行き来する「タスクスイッチング」に過ぎません。

この切り替え作業には、脳にとって無視できない「スイッチング・コスト」がかかります。タスクを切り替えるたびに、それまでの作業の状態を一時保存し、新しい作業のルールを読み込み直す時間が生まれ、これが反応の遅れやミスの増加として表れます。切り替えの回数が増えるほど、このコストは積み重なっていきます。

「23分」の空白時間が生まれる

さらに見過ごされがちなのが、一度中断されたタスクに戻るまでにかかる時間です。カリフォルニア大学アーバイン校の研究では、作業中にメールや通知で中断された場合、元のタスクに戻ってくるまで平均23分15秒かかることが示されています。

ここで注意したいのは、この23分15秒は「集中し続けて元の深さに戻るまでの時間」ではないという点です。実際には、中断のあと人は別の作業を2つほど挟んでから元のタスクに戻ってくることが多く、この数字はその寄り道も含めた時間です。それでも「数秒スマホを見ただけ」のつもりが、体感よりずっと長く尾を引くという結論は変わりません。

シングルタスクこそが最強の戦略

圧倒的な成果を出す人々は、複数のことを器用にこなすのではなく、一つのことに完全に没入する技術に長けています。だからこそ、「やらないことリスト」によって環境を整える必要があります。作業中に不要なブラウザのタブを閉じること、スマホを物理的に遠ざけること。切り替えの回数そのものを減らすことが、遠回りに見えていちばんの近道です。

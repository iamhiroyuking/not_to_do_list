完璧主義の呪縛

「完璧に準備が整ってから始めよう」「100点の成果が出せないなら意味がない」。この考え方が、行動を抑制し、成長のチャンスを奪うブレーキになることがあります。

「先延ばし」の正体は、思ったより単純ではない

「先延ばしの原因は完璧主義だ」という説明はよく聞きますが、大規模な研究の蓄積を見る限り、両者の結びつきはそれほど強くありません。先延ばしをより強く説明するのは、「その作業がどれだけ嫌か」「自分にできる自信がどれくらいあるか」「衝動的になりやすいか」といった要因です。

もうひとつ有力な説明が、「先延ばしは気分の応急処置」だという見方です。嫌な作業に向き合うと生まれる不快な気分を、いったん脇に置きたくて別のことに手を伸ばす。先延ばしは、今の気分を優先した結果として起きると考えると、単なる怠慢や完璧主義という話より、実感に近いはずです。

「完了」は「完璧」に勝る

原因が何であれ、対処の方向性は変わりません。シリコンバレーには「Done is better than perfect（完了は完璧に勝る）」という有名な格言があります。100点の成果を1回出すことにこだわるより、60点でも形にして、そこからフィードバックを得て直していく方が、結果的に前へ進みます。

これは筋力トレーニングや語学学習も同じです。体調が万全でないからとジムに行かない100点主義よりも、スクワット1セットだけでも実行する「継続主義」が最終的に100kgのベンチプレスを可能にします。「完璧さ」ではなく「一歩前進」を称えるマインドセットへの転換が効きます。

あきらめる勇気を持つ

「やらないことリスト」には、自分がこだわりすぎてしまいがちな「枝葉末節」を加えましょう。「細部のデザインに1時間以上かけない」「全ての単語を覚えるまで問題集を進めない」といったルールです。完璧を目指す気持ちを手放し、まずは「未完成のまま世に出す」「不格好でも続ける」ことを自分に許してあげてください。

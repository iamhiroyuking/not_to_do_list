偽りの報酬

脳は時として、あなたを幸せにするためではなく、ただ「行動させるため」にあなたを誘惑します。これが、悪習慣がもたらす「偽りの報酬」の正体です。

ドーパミンは「快楽」ではない

神経科学の研究の積み重ねから、ドーパミンは快楽そのものを生む物質というより、「欲しい」という期待を生む物質だという見方が有力になっています。「スマホを見れば面白い情報があるかも」「お菓子を食べれば満足できるかも」という期待を抱かせ、あなたを突き動かします。しかし、実際にその行動をとった後に得られるのは、期待したほどの快楽ではなく、むしろ虚脱感や自己嫌悪である場合が少なくありません。研究では「欲しくなる（wanting）」と「好き・満足（liking）」は別の仕組みだとされていて、ドーパミンが強く関わるのは主に前者です。

報酬系のハイジャック

投資の短期的な値動きをチェックしたり、SNSの通知を追いかけたりする時、脳内ではドーパミンが放出されています。これは、原始時代の人間が獲物を見つけた時の反応と同じ仕組みだと考えられています。デジタルデバイスや刺激の強い食品がこの仕組みを強く刺激する、という比喩はよく使われますが、依存症の研究がもともと薬物を対象にしてきたものである以上、「ハイジャック」の強さが薬物と同じ程度かどうかは、まだ議論の途中です。それでも、本来向かうべき長期的な目標から注意を逸らされる感覚そのものは、多くの人が実感として持っているはずです。

「脳の嘘」を見破る

誘惑に襲われた時、それは「あなたがそれを本当に欲している」のではなく、「欲しくなる仕組み」が先に反応しているだけかもしれません。このメカニズムを知ることで、衝動を一歩引いた視点で観察できるようになります。次にスマホに手が伸びそうになったら、自分に問いかけてみてください。「これは本物の満足か、それとも期待させられているだけか？」と。

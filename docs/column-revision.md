# コラム改稿の方針

現在のコラム10本はAI生成であり、**再現性が疑問視されている説や、出典不明の数字を
断定的に書いている箇所がある**。改稿の共通ルールをここにまとめる。
個別の作業は GitHub Issue に分けてある。

## なぜやるか

App Store審査のためではない（AI生成そのものは禁止されていない）。理由は2つ。

1. **中身が間違っていると、読む人に損をさせる。** このアプリは行動を変えることを
   目的にしている。根拠の弱い話で行動を変えさせるのは、アプリの目的に反する
2. **ポートフォリオとして見せた時の弱点になる。** 詳しい人が読めば一目でわかる

## 進め方

記事ごとに、以下を1サイクルとする。

| | 担当 | やること |
|---|---|---|
| 1 | 本人 | その記事のテーマでNotebookLMのノートブックを作る |
| 2 | 本人 | Issueに挙げた文献・資料を集めて放り込む |
| 3 | 本人 | NotebookLMに要点を出させ、Issueにコメントで貼る |
| 4 | Claude | 集まった資料をもとに本文を書き直す |
| 5 | 本人 | 事実確認して反映 |

**ノートブックは記事ごとに分ける。** 1つにまとめると資料が混ざり、
どの主張がどの文献に由来するのか追えなくなる。

## 書き方のルール

### 1. 断定を下げる

| ❌ 現在 | ✅ 改稿後 |
|---|---|
| 心理学や脳科学が示す事実は異なります | 〜という説が広く知られています |
| 〜であることがわかっています | 〜と説明されることが多いです |
| 〜が証明されています | 〜を示した研究があります |

**例外**：出典が明確で追試も通っている主張は、断定してよい。
むしろ断定すべきである（例：`problem4` の睡眠と血中アルコール濃度）。
下げるのは根拠が弱いものだけで、全部を曖昧にするのは改悪になる。

### 2. 出典を1行付ける

記事末尾に置く。リンクは不要（アプリはオフラインで動くため）。

```html
<p class="source">Dawson, D. &amp; Reid, K. (1997). Fatigue, alcohol and
performance impairment. <em>Nature</em>, 388, 235.</p>
```

`style.css` に `.source` を追加する（小さめ・`--text-secondary`）。

### 3. 出典を出せない数字は消す

「〜と言われています」を付けても救えない。**書かない**のが正解。
現在のコラムで該当するものは各Issueに挙げてある。

### 4. 断定を下げても実用的な助言は残す

読者が受け取るべきは行動の指針であって、学説の解説ではない。
根拠が弱くなった場合も、**助言そのものは経験則として残してよい**。
「研究が示す」を「やってみると効く」に言い換えるだけで成立することが多い。

### 5. アプリの仕様と食い違わせない

コラムはアプリの外部資料ではなく、アプリの一部である。
**要件定義 v2（`requirements.md`）と矛盾する記述を残さない。**

現時点で判明している矛盾：

- `action4` に「せっかく続いている10日間の記録がゼロになってしまう」とあるが、
  v2では**1日の猶予がある**（3.2）ため、1回の失敗ではゼロにならない
- 逆に `action5`「2日連続でサボらない」は、**v2の判定ルールそのもの**。
  ここは強化し、アプリの仕組みと結び付けて書く

## 優先順位

| 優先 | 記事 | 理由 |
|---|---|---|
| **高** | `problem1` 意志力は消耗する | 中核の主張（自我消耗）が追試で支持されていない |
| **高** | `problem2` マルチタスクの幻想 | 出典が否定された数字と、見出しと本文の食い違い |
| 中 | `problem5` 偽りの報酬 | 主張は妥当だが「最新の脳科学」が誇張 |
| 中 | `action4` 記録して可視化する | アプリの仕様と矛盾（上記） |
| 中 | `problem3` 完璧主義の呪縛 | 根拠の提示が無い |
| 低 | `problem4` 睡眠不足 | **内容は正確。出典を足すだけで最良の記事になる** |
| 低 | `action2` 代わりの行動 | エビデンスが最も強いテーマ。出典を足すだけ |
| 低 | `action1` `action3` `action5` | 実践論であり、事実の主張が少ない |

## 未使用ファイルの扱い

- `other_html/other2.html` 〜 `other5.html` は**中身が空**（1バイト）
- `otherColumn.json` は「準備中のコラム」1件のみで、`loadAllData()` から読まれていない

第3セクションを作るなら復活させる。作らないなら削除する（→ 別Issue）。

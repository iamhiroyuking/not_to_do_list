# NotebookLM でコラムの材料を集める

コラム改稿（Issue #1〜#11）で、記事ごとに使うノートブックとプロンプト。
共通の方針は [column-revision.md](column-revision.md) を参照。

## 役割分担

| | 担当 | やること |
|---|---|---|
| 資料集め | 本人 | 下の表の文献を探してノートブックに入れる |
| 事実確認 | NotebookLM | 「記事の主張は資料で支持されるか」を突き合わせる |
| 執筆 | Claude | 確認結果をもとに本文を書き直す |
| 反映 | 本人 | 読んで確認し、HTMLへ入れる |

**NotebookLMに記事そのものを書かせない。** 理由は2つ。

1. **NotebookLMは入れた資料の中でしか答えられない。** これは事実確認では長所だが、
   記事としての語り口や、アプリの世界観との整合（「据え置き」「観測日数」といった
   このアプリ固有の言葉）は持っていない
2. 現在のコラムがAI生成であることが問題なのに、**別のAIに書かせても同じ問題が残る**。
   NotebookLMを使う意味は「出典に紐づけること」であって、文章を出させることではない

**NotebookLMは資料を探してはくれない。** 入れた資料がすべてなので、
集める段階の質がそのまま結果の質になる。

## 進め方（1記事につき1サイクル）

1. **ノートブックを新規作成**（記事ごとに分ける。混ぜると出典が追えなくなる）
2. **記事の現在の本文をソースとして入れる**（下のコマンドで取り出せる）
3. **文献を集めて入れる**
4. **プロンプトA（監査）**を実行 → 結果をIssueにコメントで貼る
5. **プロンプトB（材料）**を実行 → 結果をIssueにコメントで貼る
6. Claudeが本文を書き直す

### 記事の本文を取り出すコマンド

```bash
python3 -c "
import re,sys,html
t=open(sys.argv[1],encoding='utf-8').read()
t=re.sub(r'<[^>]+>','\n',t)
print(re.sub(r'\n{2,}','\n',html.unescape(t)).strip())
" "not_to_do_list/columnfile/html_css_file/problem_html/problem1.html"
```

出力をコピーして、NotebookLMに「テキストを貼り付け」で入れる。
ソース名は **記事原文** にしておくと、下のプロンプトがそのまま使える。

## プロンプトA — 主張の監査

> アップロードした資料だけを根拠に答えてください。
>
> 「記事原文」というソースに、ある記事の本文が入っています。
> この本文に含まれる**事実の主張**を1つずつ取り出し、次の表にしてください。
>
> | 記事の主張（原文から引用） | 資料での扱い | 根拠の強さ | 出典 |
>
> 「資料での扱い」は次の4つから選んでください。
> - **支持** — 資料が明確に支持している
> - **部分的** — 条件付き・限定的にのみ支持されている
> - **反証** — 資料が否定している、または追試で再現されていない
> - **資料に無い** — アップロードした資料からは判断できない
>
> 「根拠の強さ」は次から選んでください。
> - メタ分析／事前登録の追試
> - 単一の実験研究
> - 総説・一般向け書籍
> - 出所不明
>
> **重要**: 資料に書かれていないことは推測しないでください。
> 判断できないものは必ず「資料に無い」としてください。
> 資料に無い主張を補うために一般知識を使わないでください。

## プロンプトB — 書き直しの材料

> 資料だけを根拠に、次の4つを出してください。
>
> 1. **断定してよい主張**（追試や複数の研究で支持されているもの）を3つまで。各1文。
> 2. **断定を避けるべき主張**（議論がある／再現されていない）を3つまで。
>    各1文と、なぜ議論があるのかを一言。
> 3. **読者が今日から取れる具体的な行動**を3つまで。資料に根拠があるものだけ。
> 4. **記事末尾に載せる出典**を次の形式で。
>    `著者名 (発表年). タイトル. 掲載誌, 巻, ページ.`
>
> 数字（％・分・回数など）を出す場合は、**どの資料のどこに書かれているか**を必ず添えてください。
> 出典を示せない数字は出さないでください。

## プロンプトC — 反証の確認（🔴 の記事だけ）

> 「（説の名前）」について、資料の中に次のものがあれば挙げてください。
>
> - 追試（replication）の結果と、その規模
> - メタ分析の結論
> - 元の研究への批判、または著者自身による訂正・撤回
> - その説に代わる説明
>
> 資料に無ければ「資料に無い」と答えてください。**推測で補わないでください。**

## Issueへの貼り方

プロンプトA・Bの結果を、そのままIssueにコメントで貼ってください。
表が崩れても構いません。**出典の情報だけは省略しないでください。**

貼ったあとに「#2 の材料が揃いました」と伝えてもらえれば、本文を書き直します。
